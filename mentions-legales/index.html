En bref : ce site ne dépose aucun cookie, ne mesure pas l'audience et ne vend rien pour l'instant. Vos textes et vos fichiers restent dans votre appareil.

Données personnelles

  • Ce que vous saisissez reste dans votre appareil. Les prompts, mots de passe, photos, politiques et listes sont traités dans votre navigateur. Le site n'a pas de serveur pour les recevoir.
  • Ce qui est gardé dans votre navigateur, et seulement là : le thème clair ou sombre, la langue, l'historique des prompts et la liste d'abonnements si vous l'utilisez. Vous pouvez tout effacer depuis les réglages de votre navigateur.
  • La relecture par une IA, sur l'accueil, est facultative. Si vous l'utilisez, votre texte part directement de votre navigateur vers le fournisseur que vous choisissez (Anthropic, OpenAI ou un autre), avec votre propre clé. Ce fournisseur applique alors sa propre politique de confidentialité. Votre clé n'est gardée dans le navigateur que si vous cochez la case prévue.
  • La liste d'information par courriel. Si vous écrivez pour vous inscrire, votre adresse sert uniquement à vous envoyer au plus un message par mois sur les nouveaux outils. Elle n'est ni revendue ni transmise. Un message avec « stop » suffit pour être retiré. Vous pouvez aussi demander à consulter ou supprimer vos données à la même adresse, et saisir la CNIL si vous estimez que vos droits ne sont pas respectés.
  • Comme tout hébergeur web, GitHub peut enregistrer des informations techniques lors du chargement des pages (adresse IP notamment). Voir la déclaration de confidentialité de GitHub.

Cookies

Ce site ne dépose aucun cookie et n'utilise aucun traceur ni outil de mesure d'audience. Les seules informations gardées dans votre navigateur servent les fonctions que vous utilisez (thème, historique, liste d'abonnements). Il n'y a donc pas de bandeau de consentement.

Conditions d'utilisation

  • Vous restez responsable de ce que vous faites des prompts et des résultats produits.
  • Le code source est publié sous licence GPL-3.0.

Vente et remboursement

Rien n'est vendu sur ce site pour l'instant. Si une offre payante ouvre, ses conditions de vente et de remboursement seront publiées ici avant toute vente.

Tout est calculé dans votre navigateur. Aucune donnée n'est transmise, stockée ni analysée ailleurs.
